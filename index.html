VOXHAVENVOXEL SURVIVAL SANDBOX

Dig deeper!

Carve a home out of an endless world.
Mine deep, build tall, survive the dark.

Goal

There is no fixed ending — gather resources, master every tool tier and build whatever you imagine. Nightfall brings hostiles, so light your home well.

Controls

W A S D move
Space jump
Shift sneak
Ctrl sprint
LMB mine / hit
RMB place / use
1–9 hotbar
Wheel cycle
E satchel
C crafting
M map
G guide
F eat
Q drop
F5 camera
Esc menu

First Steps

  1. Punch trees → Planks → Sticks.
  2. Craft an Crafting Table and place it.
  3. Timber pick → stone → copper → iron → Aurorite.
  4. Make torches before dusk.

Controller

Plug in a gamepad any time — sticks move and look, RT mines, LT places, A jumps, Y opens the satchel, bumpers cycle the hotbar.

VOXHAVEN — an original voxel sandbox. All artwork, creatures, sounds, music and interface are generated procedurally from code in this project; no third-party game assets are used.
Built with WebGL. Worlds save to your browser's local storage.
